What the sponsor stack actually does here.

Zetaris · data layer

Two sources, one query

Contract and policy live in different systems. Zetaris joins them in a single statement per check, and the SQL is printed on every card so a judge can rerun it.

Meterless · H-Mem engine

Memory that catches repeats

Every claim and verdict is stored. A reworded promise later in the call, or on a later call, surfaces the earlier claim with its time and verdict. Persists across restarts. Conformance tests in agent/tests/test_memory.py.

NVIDIA · Nemotron via Nightshift

Two calls per check, model shown

Route and judge both run on Nemotron 3.5 Lightning through the local Nightshift runtime. Reasoning mode off cut the verdict step from 19 s to about 2 s. The served model id is on every card and in every trace log line.

Unique to this build
  • The model is only allowed to point at text. Clause words come from Zetaris by id; conflicting phrases are accepted only if they are verbatim substrings, otherwise dropped.
  • Contradictions require a clause id the judge named. Failures resolve to unclear. Zero false accusations on the labeled set.
  • One trace line per check (topic, clause, verdict, model, timings), so every answer can be audited after the call.
